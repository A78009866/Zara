# ZARA — واجهة متجر تجريبية

واجهة متجر أزياء مستقلة باللغة العربية، متجاوبة مع الهاتف والحاسوب، مبنية بـ React وVite وجاهزة للنشر على Vercel. هذا المشروع **غير تابع لعلامة Zara العالمية**.

**النسخة المنشورة:** https://zara-store-a78009866.vercel.app/

## الوظائف

- تصفح المنتجات وتصفية الفئات والبحث والترتيب حسب السعر.
- عرض تفاصيل المنتج، اختيار المقاس، المفضلة، وحقيبة التسوق مع حفظها على جهاز الزائر.
- إمكانية تجهيز طلب عبر واتساب عند ضبط رقم المتجر (انظر أدناه).
- الصور والمنتجات والأسعار نموذجية، وليست عرضاً لمنتجات حقيقية. صور المشروع مولدة رقمياً.

## تشغيل المشروع محلياً

```bash
npm install
npm run dev
```

وللتحقق من نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## تفعيل طلبات واتساب (اختياري)

بشكل افتراضي استقبال الطلبات **غير مفعّل**، ويعرض الموقع تنبيهاً واضحاً بذلك؛ لا يتم إرسال بيانات الزائر أو تحصيل أي أموال. لتفعيل إنشاء رسالة طلب على واتساب:

1. انسخ `.env.example` إلى `.env.local` (لا ترفع الملف الخاص إلى Git).
2. عيّن `VITE_WHATSAPP_NUMBER` إلى رقم واتساب الخاص بالمتجر **بالصيغة الدولية، أرقام فقط دون علامة + أو مسافات**. مثال تنسيقي: رقم جزائري يبدأ بـ `213` ثم رقم الهاتف دون الصفر الأول.
3. أعد تشغيل خادم التطوير أو أعد بناء المشروع. عند النشر في Vercel، أضف المتغير نفسه من **Project Settings → Environment Variables** ثم أنشئ نشراً جديداً.
4. يستكمل العميل إرسال رسالة الطلب يدوياً من واتساب. لا يتضمن المشروع حالياً قاعدة بيانات، أو إدارة مخزون، أو بوابة دفع إلكتروني، أو حساب رسوم شحن.

استبدل المنتجات التجريبية وبياناتها في `src/products.js` والصور في `public/images/` بمنتجاتك الحقيقية قبل البيع. يجب ضبط سياسات البيع والتوصيل وفق نشاطك، والتحقق من توفر البضاعة قبل قبول الطلبات.

## النشر على Vercel

استورد المستودع في Vercel أو اربطه من إعدادات المشروع. إعدادات البناء المحددة في `vercel.json` هي: إطار Vite، وأمر البناء `npm run build`، ومجلد الإخراج `dist`. إذا كانت المشاريع مربوطة بالمستودع فسيؤدي الدفع إلى الفرع الإنتاجي إلى نشر جديد تلقائياً.

**الأمان:** لا تضف توكنات GitHub أو Vercel أو أي مفاتيح سرية إلى ملفات المستودع. أي متغير يبدأ بـ `VITE_` يصبح مرئياً في المتصفح، لذا لا تضع فيه أسراراً.
